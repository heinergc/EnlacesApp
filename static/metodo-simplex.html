¿Qué es el Método Simplex?

El Método Simplex es un algoritmo iterativo desarrollado por George Dantzig en 1947 para resolver problemas de Programación Lineal (PL). Es uno de los métodos más utilizados en Investigación de Operaciones para optimizar (maximizar o minimizar) una función objetivo sujeta a restricciones lineales.

Componentes de un Problema de Programación Lineal

1. Función Objetivo

Es la función que queremos maximizar o minimizar. Por ejemplo:

Maximizar: Z = c₁x₁ + c₂x₂ + ... + cₙxₙ

Donde Z es el valor que queremos optimizar, x₁, x₂, ..., xₙ son las variables de decisión, y c₁, c₂, ..., cₙ son los coeficientes.

2. Restricciones

Son las limitaciones del problema, expresadas como desigualdades o igualdades:

a₁₁x₁ + a₁₂x₂ + ... + a₁ₙxₙ ≤ b₁
a₂₁x₁ + a₂₂x₂ + ... + a₂ₙxₙ ≤ b₂
...
aₘ₁x₁ + aₘ₂x₂ + ... + aₘₙxₙ ≤ bₘ

3. Restricciones de No Negatividad

x₁, x₂, ..., xₙ ≥ 0

Forma Estándar

Para aplicar el Método Simplex, el problema debe estar en forma estándar:

  • La función objetivo debe ser de maximización
  • Todas las restricciones deben ser igualdades
  • Todas las variables deben ser no negativas
  • Los términos independientes (lado derecho) deben ser no negativos

Conversión a Forma Estándar

Problema original:

Maximizar: Z = 3x₁ + 2x₂
Sujeto a:
2x₁ + x₂ ≤ 18
2x₁ + 3x₂ ≤ 42
3x₁ + x₂ ≤ 24
x₁, x₂ ≥ 0

Forma estándar (agregando variables de holgura):

Maximizar: Z = 3x₁ + 2x₂ + 0s₁ + 0s₂ + 0s₃
Sujeto a:
2x₁ + x₂ + s₁ = 18
2x₁ + 3x₂ + s₂ = 42
3x₁ + x₂ + s₃ = 24
x₁, x₂, s₁, s₂, s₃ ≥ 0

Variables de Holgura

Las variables de holgura (slack variables) se agregan a las restricciones de tipo "≤" para convertirlas en igualdades. Representan los recursos no utilizados.

Por ejemplo, si tenemos: 2x₁ + x₂ ≤ 18

Agregamos s₁: 2x₁ + x₂ + s₁ = 18

Paso 1: Convertir a Forma Estándar

Transformar el problema agregando variables de holgura, exceso o artificiales según corresponda.

Paso 2: Construir la Tabla Inicial (Tableau)

Organizar los coeficientes en una tabla que incluye:

  • Variables básicas: Las variables de holgura inicialmente
  • Columnas: Una por cada variable (decisión y holgura)
  • Filas: Una por cada restricción + fila Z
  • Lado derecho: Los valores bᵢ

Paso 3: Identificar la Columna Pivote (Variable Entrante)

En la fila Z, buscar el valor más negativo. Esta columna indica la variable que entrará a la base.

Criterio: Si todos los valores en la fila Z son ≥ 0, la solución es óptima.

Paso 4: Identificar la Fila Pivote (Variable Saliente)

Calcular el cociente mínimo dividiendo el lado derecho entre los elementos positivos de la columna pivote:

Cociente = bᵢ / aᵢⱼ (donde aᵢⱼ > 0)

La fila con el menor cociente positivo es la fila pivote.

Paso 5: Pivoteo (Operaciones de Fila)

El elemento pivote es la intersección de la columna y fila pivote.

Operaciones:

  1. Normalizar fila pivote: Dividir toda la fila entre el elemento pivote para que este sea 1
  2. Hacer ceros: Para cada otra fila (incluyendo Z), hacer operaciones de fila para que el elemento en la columna pivote sea 0
Nueva fila = Fila actual - (coeficiente en columna pivote) × Nueva fila pivote

Paso 6: Verificar Optimalidad

Revisar la fila Z:

  • Si todos los coeficientes son ≥ 0: Solución óptima encontrada
  • Si hay valores negativos: Regresar al Paso 3

Interpretación de la Solución

Cuando el algoritmo termina:

  • Variables básicas: Sus valores están en el lado derecho
  • Variables no básicas: Tienen valor 0
  • Valor óptimo de Z: Está en la intersección de la fila Z con la columna del lado derecho

Ejemplos para Practicar

Resuelve estos problemas aplicando el Método Simplex:

Ejercicio 1: Problema de Producción

Una empresa fabrica sillas y mesas. Cada silla genera $40 de ganancia y cada mesa $30.

Maximizar: Z = 40x₁ + 30x₂

Sujeto a:
x₁ + x₂ ≤ 12 (Madera disponible)
2x₁ + x₂ ≤ 16 (Tiempo de ensamblaje)
x₁, x₂ ≥ 0

Pista: Agrega variables de holgura s₁ y s₂, luego construye la tabla inicial.

Ejercicio 2: Problema de Dieta

Un nutricionista quiere minimizar el costo de una dieta que cumpla con requerimientos nutricionales.

Minimizar: Z = 2x₁ + 3x₂

Sujeto a:
4x₁ + 2x₂ ≥ 20 (Proteínas)
2x₁ + 5x₂ ≥ 30 (Vitaminas)
x₁, x₂ ≥ 0

Nota: Para minimización, convierte a maximización: Maximizar Z' = -2x₁ - 3x₂

Ejercicio 3: Problema de Transporte

Maximizar: Z = 5x₁ + 4x₂ + 6x₃

Sujeto a:
x₁ + x₂ + x₃ ≤ 100
2x₁ + x₂ + 3x₃ ≤ 200
x₁ + 2x₂ + x₃ ≤ 150
x₁, x₂, x₃ ≥ 0

Consejos para el Éxito

  • ✅ Siempre verifique que el problema esté en forma estándar antes de empezar
  • ✅ Revise cuidadosamente los cálculos en cada iteración
  • ✅ El elemento pivote nunca debe ser cero o negativo
  • ✅ Si hay empates en el cociente mínimo, elija arbitrariamente
  • ✅ Practique con problemas pequeños antes de abordar problemas grandes
